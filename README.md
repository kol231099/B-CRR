# B-CRR｜根尖片骨水平冠根比自動量測

從一張牙科根尖片（periapical radiograph）自動定位七個解剖特徵點，
算出三項與牙齒鬆動相關的幾何指標。

**線上展示** — <https://pcastandardllm.online>

---

## 這個專案在做什麼

牙齒會不會鬆動，關鍵不只是齒槽骨流失了多少，而是**露出骨頭外的那段**
與**還埋在骨頭裡的那段**的比例。文獻把這個比例稱為 **B-CRR**（bone-level
crown-to-root ratio）。同樣流失三成骨頭，短根的牙齒可能已經開始搖，
長根的還很穩。

但要算出這個比例，醫師得在影像上逐點定位、拉線、量長度——太費工，
所以臨床上幾乎沒人做。本專案把整條流程自動化。

### 三項指標

| 指標 | 定義 | 意義 |
| --- | --- | --- |
| **CRR** | 牙冠長 ÷ 牙根長 | 牙齒本身的比例 |
| **ABLR** | 齒槽骨流失的比例 | 地基少了多少 |
| **B-CRR** | 骨脊以上 ÷ 骨脊以下 | **槓桿比，與鬆動度相關** |

程式同時以 `JS/KS` 與 `(CRR+ABLR)/(1−ABLR)` 兩種方式計算 B-CRR
互相驗證，測試集上兩者差異皆小於 1e-15。

## 方法

兩階段模型，接一段純幾何推導：

```
根尖片
  │
  ├─ Mask R-CNN ────────────► 每顆牙的旋轉框（OBB）
  │
  ├─ 轉正裁切 → U-Net(HRNet-w32) 五折集成 ──► 牙齒遮罩
  │
  └─ 幾何推導（不靠模型猜座標）
       ├ PCA 主軸 ─────────────────► 長軸
       ├ 半寬剖面分段線性擬合 ───────► C、D（CEJ）
       ├ 厚度—亮度殘差 ─────────────► A、B（邊緣嵴）
       ├ 根尖最低 1% 中位數 ─────────► G（根尖）
       └ 牙根外側亮度階梯擬合 ────────► E、F（齒槽脊）
```

**七個點各有各的演算法**，不是丟給模型回歸座標。代價是比較難做，
好處是每一個點都有幾何依據、可以在圖上目視核對，而且**推導不出來時
系統會明說「這顆量不出來」**，不會硬給一個數字。

詳細推導見 [`doc/methods.md`](doc/methods.md)。

## 關於原始文獻

本研究複現 Li et al. (2024) 的量測方法時，發現該方法**無法被客觀複現**：

- 牙齒長軸的定義是人工目視的判斷過程，未給出任何幾何構造
- 特徵點 C、D 在文中被描述成 DEJ 與 CEJ 兩種不同的解剖構造
- 關鍵參數 PRW 的數值在表格與內文相差約十倍

因此本專案重新定義了一套**可以被程式執行**的操作型判準，
並逐項記錄與原文的差異：[`doc/paper_issues.md`](doc/paper_issues.md)。

> Li JM, Wang XE, et al. *BMC Oral Health* 2024; 24: 1232.

## 網站

`site/` 是完整的前端，無框架、無建置步驟、**零第三方 JavaScript 相依**。

### 端對端加密

保險庫裡的影像、檔名與分析結果，**在離開使用者的電腦之前就已加密**：

```
通關密語 ──PBKDF2-SHA256, 600,000 次──► 包裝鑰 A ─┐
                                                 ├─► 各鎖一份資料金鑰
救援碼（約 198 位元熵）─────────────────► 包裝鑰 B ─┘
```

伺服器只保管兩個鎖住的盒子，**沒有任何一把鑰匙**。使用者忘記密語時
我們無法重設——這正是「我們看不到」的證明。

加密實作在 [`site/vault.html`](site/vault.html) 的 `CRY` 模組
（AES-256-GCM / WebCrypto），伺服器端存取層在
[`server/vault.py`](server/vault.py)。

## 執行

### 本機

```bash
pip install -r server/requirements.txt
bash server/run-local.sh
```

開 <http://127.0.0.1:8900/vault.html>。有 Apple Silicon 或 CUDA
會自動使用 GPU（`BCRR_DEVICE` 可覆寫）。

**模型權重不在版控中**（單檔超過 GitHub 上限），
可由 `koi/setA/scripts/` 的訓練腳本重新產生。

### 部署

```bash
BCRR_HOST=root@你的主機 bash server/deploy.sh
```

## 已知限制

誠實揭露：

- 測試集 21 張影像、60 顆牙，其中 **38 顆量得出指標（63%）**
- 尚無與人工量測的一致性分析（ICC、Bland–Altman）
- 尚無臨床醫師的正式試用回饋
- 雲端主機無顯卡，單張約 20 秒；本機 GPU 約 1 秒
