## 1. 研究材料

### 1.1 影像資料

本研究使用根尖片（periapical radiograph）共 300 張，以單顆牙齒為單位裁切後進行分析。

目前已完成標註者為 2 張（`7.jpg`、`13.jpg`），影像尺寸分別為 377 × 1195 與 274 × 715 像素。**本文件所報告的量化結果皆基於此 2 顆牙齒的先導測試（pilot test），樣本數極小，僅足以驗證方法的可行性，不足以支持統計推論。**

### 1.2 影像標註

標註使用 labelme（版本 5.2.1）以多邊形（polygon）方式進行。本研究所使用的標註類別為：

| 標籤 | 定義 |
| --- | --- |
| `1` | 整顆牙齒（牙冠 + 牙根），以牙齒外表面為界 |

選擇「整顆牙齒」作為唯一必要類別的理由是：牙齒外表面（琺瑯質表面與牙骨質表面）為**真實存在的物理界面**，在影像上與牙周膜間隙、骨髓腔之間有明確的密度差異，標註者之間的一致性較高。相對地，牙冠內部的琺瑯質與牙本質在 X 光投影中沿射線方向重疊，兩者之間並不存在可在二維影像上明確劃分的邊界，故不採用為分割類別。

## 2. 方法

### 2.1 由標註多邊形取得像素點集

將 labelme 標註的多邊形頂點以 OpenCV 的 `fillPoly` 光柵化（rasterise）為二值遮罩（binary mask），再取其所有前景像素座標，構成點集

$$P = \{\mathbf{p}_i = (x_i, y_i)\}_{i=1}^{N}$$

其中座標系為影像座標（x 向右、**y 向下**為正）。

**此處直接採用遮罩像素而非多邊形頂點，為一關鍵設計選擇。** 標註者在輪廓曲率大處點取頂點較密、在平直處較疏，故頂點集合對牙齒形狀而言是**有偏的取樣**，會使後續的主成分分析偏向頂點密集的區域。遮罩像素則為對牙齒**面積的均勻取樣**，符合主成分分析對輸入分布的假設。

本研究中兩顆牙齒的點集大小分別為 226,482 與 108,073 個像素。

### 2.2 以主成分分析擬合長軸

計算點集的形心與共變異數矩陣：

$$\bar{\mathbf{p}} = \frac{1}{N}\sum_{i=1}^{N}\mathbf{p}_i, \qquad
\mathbf{q}_i = \mathbf{p}_i - \bar{\mathbf{p}}, \qquad
\mathbf{C} = \frac{1}{N-1}\sum_{i=1}^{N}\mathbf{q}_i\mathbf{q}_i^{\mathsf{T}}$$

其中 $\mathbf{C}$ 為 2 × 2 對稱矩陣。對其進行特徵分解：

$$\mathbf{C}\,\mathbf{v}_k = \lambda_k \mathbf{v}_k, \qquad \lambda_1 \geq \lambda_2$$

$\mathbf{v}_1$ 即為牙齒的**長軸方向**（最大變異方向），$\mathbf{v}_2$ 為與其正交的**短軸方向**；$\lambda_1$、$\lambda_2$ 分別為沿長軸與短軸的變異數。

實作上使用 `numpy.linalg.eigh`（針對對稱矩陣的特徵分解）。需注意該函式回傳的特徵值為**升序**排列且特徵向量以**行向量**（column）形式給出，需重新排序後取用。

#### 2.2.1 共變異數法與奇異值分解的選擇

主成分分析亦可透過對置中資料矩陣直接做奇異值分解（SVD）求得，兩者在數學上等價：若 $\mathbf{Q} = \mathbf{U}\mathbf{S}\mathbf{V}^{\mathsf{T}}$，則 $\mathbf{Q}^{\mathsf{T}}\mathbf{Q} = \mathbf{V}\mathbf{S}^2\mathbf{V}^{\mathsf{T}}$，故右奇異向量即為特徵向量，且 $\lambda_k = s_k^2/(N-1)$。

數值線性代數的通則建議避免顯式形成 $\mathbf{Q}^{\mathsf{T}}\mathbf{Q}$，因為此運算會使條件數平方（$\kappa(\mathbf{Q}^{\mathsf{T}}\mathbf{Q}) = \kappa(\mathbf{Q})^2$），放大數值誤差。然而該通則適用於欄數眾多、條件數不佳的問題；本研究的資料矩陣僅有 2 欄，條件數約為 4，兩種方法的實測差異如下：

| 比較項目 | 結果 |
| --- | --- |
| 長軸方向差異 | 0°（7.jpg）／8.5 × 10⁻⁷ 度（13.jpg） |
| 特徵值相對差異 | 約 4 × 10⁻¹⁵（浮點捨入誤差等級） |
| 計算時間（7.jpg, N = 226,482） | 共變異數法 3.56 ms／SVD 7.36 ms |
| 計算時間（13.jpg, N = 108,073） | 共變異數法 1.64 ms／SVD 3.58 ms |

兩者精度無實質差異，而共變異數法快約 2.1 倍。原因在於本問題的資料矩陣為「高瘦型」（N × 2）：共變異數法將 N 列資料壓縮為 2 × 2 矩陣後再分解，成本相當於掃描資料一次；SVD 則需額外計算並配置一個 N × 2 的左奇異向量矩陣，而該矩陣在本應用中並不需要。**故本研究採用共變異數法。**

#### 2.2.2 長短軸變異數比作為形狀品質指標

定義

$$\text{長短軸變異數比} = \frac{\lambda_1}{\lambda_2}$$

此值反映牙齒遮罩的細長程度。當其接近 1 時，形狀趨近於圓形，主軸方向不具明確意義，長軸擬合結果不可信。本研究以此值作為自動品質檢核指標，低於 3 者標記為可疑並提示人工檢視。

### 2.3 牙冠端與牙根端之判定

#### 2.3.1 問題陳述

主成分分析所得的 $\mathbf{v}_1$ 定義的是一條**無方向的直線**——$\mathbf{v}_1$ 與 $-\mathbf{v}_1$ 在數學上等價。欲建立牙齒的座標系，必須額外判定長軸的兩端何者為牙冠、何者為根尖。

#### 2.3.2 判定指標

以形心為界、沿短軸方向將點集切為兩半：

$$H^{+} = \{\mathbf{p}_i : (\mathbf{p}_i - \bar{\mathbf{p}})\cdot\mathbf{v}_1 \geq 0\}, \qquad
H^{-} = \{\mathbf{p}_i : (\mathbf{p}_i - \bar{\mathbf{p}})\cdot\mathbf{v}_1 < 0\}$$

對每一半 $H$，計算其像素在長軸與短軸方向上的投影：

$$a_i = (\mathbf{p}_i - \bar{\mathbf{p}})\cdot\mathbf{v}_1, \qquad
b_i = (\mathbf{p}_i - \bar{\mathbf{p}})\cdot\mathbf{v}_2$$

並定義**形狀比值**

$$R(H) = \frac{\operatorname{Var}(\{b_i\}_{i \in H})}{\operatorname{Var}(\{a_i\}_{i \in H})}$$

$R$ 值較大的一半判定為**牙冠端**。

#### 2.3.3 判定原理

牙冠段相對於其長度而言較為寬短（stubby），牙根段則細長（elongated）。分子 $\operatorname{Var}(b)$ 量測該半的橫向寬度、分母 $\operatorname{Var}(a)$ 量測其縱向長度，故 $R$ 即為該半的「寬長比」。

此指標的設計具有以下性質：

1. **雙向放大差異。** 牙冠半同時具有較大的分子與較小的分母，牙根半反之，兩項效果相乘。實測顯示（見 3.2 節），若僅比較 $\operatorname{Var}(b)$，兩半的差距為 2.7–2.9 倍；改用比值後擴大為 5.7–6.2 倍。

2. **無可調參數。** 主軸、形心、變異數皆有明確數學定義，不需設定任何閾值、分箱數或平滑參數，避免了參數調校導致的過度配適疑慮。

3. **無量綱。** 分子分母同為長度平方的量綱，故比值不受影像解析度與牙齒實際大小影響。此性質使該指標可用於設定**絕對信心閾值**（見下）。

4. **對局部偏移不敏感。** 變異數係對各半自身的平均值計算，而非對長軸計算，故牙冠相對於牙根軸向略有偏斜時，僅其散布程度被納入量測，偏移量本身不會使指標膨脹。

#### 2.3.4 判定信心度

定義

$$\text{margin} = \frac{R(H_{\text{牙冠}})}{R(H_{\text{牙根}})}$$

此值愈大表示兩端形狀差異愈明顯、判定愈可靠。本研究以 margin < 1.5 作為警示閾值，低於此值者標記為判定不可靠並提示人工檢視。

#### 2.3.5 關於切分位置的說明

形心並非牙齒長軸的中點，亦不對應牙冠與牙根的解剖交界。由於牙冠較為粗壯而牙根較長，形心的實際位置在本研究兩顆牙齒中皆位於**距牙冠端約 41% 處**，已深入牙根範圍。

因此「牙冠半」實際包含完整牙冠與一段冠側牙根。此一事實不影響本方法的目的——本步驟僅需區分長軸的兩端，牙冠與牙根**交界位置的判定屬於後續 CEJ 定位的任務**，兩者為獨立問題。惟此切分方式應於論文中明確敘明，以免與解剖交界混淆。

### 2.4 牙齒座標系之定義

完成上述步驟後，即可定義以牙齒自身為基準的正交座標系：

- **原點**：遮罩形心 $\bar{\mathbf{p}}$
- **$\mathbf{y}'$**：長軸單位向量，方向指向**牙冠端**
- **$\mathbf{x}'$**：與 $\mathbf{y}'$ 正交的單位向量

任一影像點 $\mathbf{p}$ 於此座標系中的座標為兩個內積：

$$x' = (\mathbf{p} - \bar{\mathbf{p}})\cdot\mathbf{x}', \qquad
y' = (\mathbf{p} - \bar{\mathbf{p}})\cdot\mathbf{y}'$$

#### 2.4.1 $\mathbf{x}'$ 的符號慣例

與 $\mathbf{y}'$ 正交的單位向量有兩個，相差一個負號。本研究固定採用

$$\mathbf{x}' = (-y'_y,\; y'_x)$$

由於影像座標系的 y 軸向下，當牙冠朝向畫面上方時 $\mathbf{y}' \approx (0, -1)$，上式給出 $\mathbf{x}' = (1, 0)$，即畫面向右。此慣例使新座標系在視覺上符合「x 向右、y 向上」的一般數學直覺。

此處涉及影像座標系與一般數學座標系之間的翻轉，是符號錯誤的常見來源，故於實作中獨立為單一函式並明確記錄，避免在程式各處重複判斷。

#### 2.4.2 剛體變換性質

上述座標轉換僅包含旋轉與平移，**不含縮放**，故為剛體變換（rigid transform）。點與點之間的距離與角度完全保持不變。

此性質對本研究至關重要：CRR 為兩段長度的比值，任何縮放失真或重採樣誤差都會直接污染測量結果。**採用解析式的座標轉換，而非實際旋轉影像像素，可完全避免內插與重採樣造成的資訊損失。** 後續所有幾何計算皆於此座標系中進行，無須產生旋轉後的影像。

## 4. 目前限制

1. **樣本數。** 本文件所有量化結果僅來自 2 顆牙齒，屬可行性驗證，不具統計代表性。後續需在完整資料集上重新評估。

2. **牙位範圍。** 本方法設計以**單根牙（前臼齒）** 為前提，與參考文獻 Li et al. (2024) 的研究對象一致。多根臼齒的根尖端在投影上可能呈現寬闊或分岔的形態，將使「牙根較細長」的判定前提失效，需另行設計判別方法。

3. **與參考文獻長軸定義之差異。** Li et al. (2024) 定義長軸時，僅取「邊緣嵴以下之牙冠」與「牙根冠側三分之二」區域，並忽略根尖三分之一的彎曲。本研究目前採用**完整牙齒遮罩**擬合長軸，與該定義不同。原因是該裁切範圍的界定需先取得邊緣嵴與 CEJ 位置，而此二者的自動定位尚未完成。此差異於論文中須明確敘明；待特徵點定位完成後應重新實作並比較兩種定義的差異。

4. **二維投影的固有限制。** 根尖片為二維投影影像，無法反映頰舌向的牙根形態與傾斜。此為根尖片測量的共同限制，參考文獻亦有述及。

5. **牙冠截斷。** 若牙冠於影像邊界處被截斷，遮罩形狀將失真，可能影響長軸擬合與牙冠端判定。本研究的 7.jpg 牙冠頂端距影像上緣僅 17 像素，屬於需留意的情形。

## 5. 實作與再現性

上述方法實作於 `scripts/find_axis.py`，主要函式對應如下：

| 函式 | 對應章節 |
| --- | --- |
| `labelme_io.mask_points()` | 2.1 由標註取得像素點集 |
| `pca()` | 2.2 主成分分析 |

| `orient_to_crown()` | 2.3 牙冠端判定 |

| `ToothFrame.to_frame()` / `to_image()` | 2.4 座標轉換 |

執行方式：

```
py scripts/find_axis.py labeled_PA --cut --profile
```

`--cut` 選項將繪出通過形心、沿 $\mathbf{x}'$ 方向的切分線並將兩半以不同顏色標示；程式同時輸出長短軸變異數比與兩半的 $R$ 值及 margin。
